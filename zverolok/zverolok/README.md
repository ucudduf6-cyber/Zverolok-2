# 🐾 ЗвероЛок

Рабочий **MVP** PWA + FastAPI + PostgreSQL/PostGIS + Redis + aiogram 3. Включает регистрацию Argon2/JWT, объявления, геопоиск, WebSocket, подписки Web Push, Telegram-привязку, единые настройки и ограничение в 10 объявлений. Это основа для доработки и тестирования, **не обещание готовности к промышленной эксплуатации**.

## Быстрый запуск

1. Установите Docker, Node.js 20+ и npm.
2. Скопируйте `.env.example` в `.env`, задайте уникальные `DB_PASSWORD`, `JWT_SECRET`, `ADMIN_PASSWORD`, токен бота и VAPID ключи. **Не публикуйте `.env` в Git**.
3. Создайте ключи VAPID, например `npx web-push generate-vapid-keys`. Заполните `VAPID_PRIVATE_KEY`, `VAPID_PUBLIC_KEY`, `VAPID_SUBJECT` в `.env`. Создайте `frontend/.env.local` со строкой `VITE_VAPID_PUBLIC_KEY=ВАШ_ПУБЛИЧНЫЙ_КЛЮЧ`.
4. В `.env` укажите `BOT_USERNAME` без @. Telegram-бот создаётся через BotFather.
5. Запустите API, БД и Redis: `docker compose up -d --build db redis api`. Затем бота: `docker compose up -d --build bot` (если токен задан).
6. Для создания администратора (опционально): `docker compose exec api python -m app.create_admin`.
7. Запустите интерфейс: `cd frontend && npm install && npm run dev`. Откройте `http://localhost:5173`.
8. Production: `npm run build`; разместите `frontend/dist` за HTTPS reverse proxy. Проксируйте `/api` и `/ws` к FastAPI, с поддержкой WebSocket Upgrade. `PUBLIC_ORIGIN` должен совпадать с точным HTTPS origin сайта. В production нужны миграции Alembic, мониторинг, ограничение запросов, CSP и аудит безопасности.

## Как установить на iPhone

1. Откройте **HTTPS-сайт** в **Safari** на iPhone.
2. Нажмите **«Поделиться»**.
3. Выберите **«На экран „Домой“»** (в некоторых версиях iOS — «Добавить на экран Домой»).
4. Назовите **«ЗвероЛок»** и нажмите **«Добавить»**.
5. Появится иконка. При нажатии сайт откроется как отдельное приложение.

На iOS Web Push доступен для установленных на домашний экран веб-приложений (iOS 16.4+) при разрешении пользователя. Запрос разрешения должен следовать нажатию кнопки. iOS не гарантирует звук или вибрацию, и фоновые уведомления требуют доступности push-сервиса и интернета. Офлайн доступна ранее закэшированная оболочка; карта, объявления и отправка данных требуют сети. В Safari iOS `beforeinstallprompt` обычно недоступен, поэтому показывается инструкция.

## Иконки и тема

**Замените `frontend/public/icons/icon-192.png` и `icon-512.png` на свои PNG того же размера.** SVG-исходник находится рядом. Файл `REPLACE_ICONS.html` содержит комментарий для дизайнера. Цвет манифеста по умолчанию `#FFFFFF`, тёмная тема переключается в интерфейсе; для динамической темы обновляйте `meta[name=theme-color]` при переключении. На iOS значок устанавливается по `apple-touch-icon`.

## Telegram

Зарегистрируйтесь на сайте, откройте настройки, нажмите «Привязать Telegram» и перейдите по ссылке. `/start` связывает аккаунт по одноразовому коду на 10 минут; бот запросит геопозицию. `/radius 5` изменит радиус, `/animals cat dog` изменит типы животных. Эти значения общие с сайтом. Для уведомлений на сайте войдите и нажмите «Уведомления» → «Разрешить».

## Ограничения и безопасность

- Демо-стиль карты MapLibre загружается по сети с `demotiles.maplibre.org`; для production используйте собственный/лицензированный tile endpoint. Карта не кэшируется для офлайн-навигации.
- Координаты по умолчанию — **демо-точка Москвы**, не местоположение пользователя. Для своего местоположения нажмите ⌖ и дайте разрешение.
- WebSocket события публичны и содержат только опубликованные объявления. Для приватных данных нужна авторизация и фильтрация.
- Уведомления отправляются в фоне через задачу процесса API; для гарантированной доставки нужна очередь задач (Celery/RQ) с ретраями и дедупликацией. На большой нагрузке геоотбор получателей следует перенести в PostGIS запросы.
- Указанный в запросе пароль администратора **намеренно не включён в исходники**: секреты нельзя фиксировать в Git. Задайте новый пароль через `.env`, не используйте опубликованные значения.
- Используйте HTTPS, безопасное хранение токенов (для production предпочтительны HttpOnly Secure cookies), rate limiting, подтверждение email, восстановление доступа, защиту от спама и логирование. В текущем MVP JWT хранится в localStorage.
- Поддерживается переключение RU/EN/ZH основных элементов интерфейса; для полной локализации нужно перевести остальные строки и ответы сервера.
